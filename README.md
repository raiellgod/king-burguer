# Burger King — Front-end Recreation

Recriação educacional inspirada na interface do site do **Burger King**, com adaptações visuais e estruturais feitas durante o desenvolvimento.

## Objetivo

Praticar a observação e reconstrução de uma interface existente, trabalhando estrutura, responsividade, composição visual e interações em JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Destaques

- Hero promocional
- Navegação responsiva
- Seções de produtos e promoções
- Área de ingredientes
- Carrossel
- Seção de menu
- Componentes e comportamentos organizados em diferentes arquivos JavaScript

## Estrutura

```text
.
├── css/
├── js/
├── public/
│   └── images/
└── index.html
```

## Aprendizados

Este projeto foi desenvolvido principalmente para praticar:

- reprodução de layouts a partir de referências;
- leitura e decomposição de interfaces;
- organização de CSS;
- comportamentos interativos com JavaScript;
- adaptação de elementos visuais de uma interface existente.
